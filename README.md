# AbiOS

Persönliche, selbst gehostete Lernplattform fürs Abitur: aktives Abrufen statt
passivem Lesen, Klausursimulation, Fehlerdatenbank, Spaced Repetition und
Lernplanung – auf Basis der eigenen Materialien.

- KI-Anbieter austauschbar (`AI_PROVIDER=…`), auch komplett lokal (Ollama)
- Daten in offenen Formaten (SQLite, JSON-Export, Originaldateien)
- Ein Docker-Container, läuft auf VPS, Heimserver oder lokal

**Status:** Phase 1 – Architektur. Siehe [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
